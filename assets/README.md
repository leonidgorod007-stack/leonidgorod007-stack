# Media drop zone

The profile README already contains hidden slots for future artwork. Nothing is
shown until a real asset is added, so the public profile never displays a broken
image.

## Banner / animation

1. Export the final banner as `hero.gif`.
2. Recommended canvas: `1600 × 500` or another ratio close to `3.2:1`.
3. Keep the file around `8 MB` or less so the profile loads quickly.
4. Keep important details away from the outer 5% of the frame.
5. Put the file in this folder and uncomment the first `<p>...</p>` block in the
   root `README.md`.

Animated GIF, APNG or animated WebP is safer for a GitHub README than embedding
an MP4 player. If the source is video, export a short, seamless loop.

## Avatar

The GitHub avatar is uploaded in account settings, not from this repository.
Recommended source: a square PNG, at least `1024 × 1024`, with a clear face or
silhouette that survives GitHub's circular crop.

## Optional second image

Name it `lab.png`, place it here, and uncomment the final image block in the
root `README.md`.
